# CostoneStatsManager

CostoneStatsManager è una piattaforma open source per la gestione e l'analisi delle statistiche delle partite di basket, pensata per società sportive, allenatori, staff tecnici e appassionati. Consente di raccogliere dati dettagliati, generare report e visualizzare l'andamento delle squadre e dei giocatori nel corso della stagione.

## Caratteristiche principali

- **Gestione squadre e giocatori**: Inserimento e modifica dei roster, anagrafiche e ruoli dei giocatori.
- **Registrazione delle partite**: Creazione di partite, inserimento dei dettagli (data, luogo, avversario), e gestione delle convocazioni.
- **Raccolta statistiche in tempo reale**: Inserimento delle statistiche individuali e di squadra durante o dopo la partita (punti, rimbalzi, assist, falli, ecc.).
- **Visualizzazione e analisi avanzata**: Grafici, report e dashboard per monitorare l’andamento stagionale e confrontare le performance.
- **Esportazione dati**: Esporta facilmente le statistiche in formato Excel/CSV o PDF.
- **Gestione utenti e permessi**: Accessi differenziati per staff, allenatori, dirigenti, ecc.

## Installazione

1. **Clona il repository**
   ```bash
   git clone https://github.com/u32634/CostoneStatsManager.git
   cd CostoneStatsManager
   ```

2. **Installa le dipendenze**
   - Se usi Python:
     ```bash
     pip install -r requirements.txt
     ```
   - Se usi Node.js:
     ```bash
     npm install
     ```

3. **Configura il database**
   - Modifica il file di configurazione (es. `.env`) con i parametri del database.

4. **Avvia l'applicazione**
   - Per sviluppo:
     ```bash
     python app.py
     ```
     oppure
     ```bash
     npm start
     ```
   - Per produzione, segui le istruzioni specifiche per il deployment.

## Utilizzo

1. Accedi all’interfaccia web all’indirizzo [http://localhost:PORT](http://localhost:PORT)
2. Crea il tuo account o accedi come amministratore.
3. Inizia a configurare squadre, inserire partite e registrare statistiche!
